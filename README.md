# Hi, I'm Shivam Sikri 👋

### RTL Design • Digital Systems • Verilog

I build and simulate digital hardware projects, with a focus on RTL design, signal processing, and reliable data movement across clock domains. My GitHub is a collection of hands-on designs—from fundamental digital building blocks to pipelined hardware.

## Featured projects

### [Pipelined 8-Point Radix-2 DIF FFT](https://github.com/ShivamSikri03/Radix2PipelinedFFT)
A Verilog FFT accelerator using fixed-point arithmetic and a three-stage pipeline. The project includes simulation and a Python/NumPy verification flow.

### [Parameterized Asynchronous FIFO](https://github.com/ShivamSikri03/Async-FIFO)
A dual-clock FIFO design using Gray-code pointers and synchronizers for clock-domain crossing. Includes testbench coverage for full/empty behavior and concurrent reads and writes.

### [Pipeline Processor Design](https://github.com/ShivamSikri03/PIPELINE-PROCESSOR-DESIGN)
A processor design project exploring pipelined digital architecture in Verilog.

### [Digital FIR Filter](https://github.com/ShivamSikri03/DESIGN-AND-SIMULATE-A-DIGITAL-FIR-FINITE-IMPULSE-RESPONSE-FILTER-USING-VERILOG)
A Verilog project focused on designing and simulating a finite impulse response filter.
